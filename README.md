# IQL-Design System

Design system documentation by Shobhit & Praveen.

🌐 **[Read the docs online →](https://iql-design.vercel.app)**

## Install in your project

​```bash
npx iql-design@latest add docs
​```

This downloads `Design.md` into your current folder.

## What's inside

- 60 Figma pages documented
- Token architecture (Primitives → Semantic → Component)
- 25+ UI components: Alert, Avatar, Badge, Button, Card, Date Picker, Input, Table, Toast, and more
- Multi-platform CI/CD: Android, iOS, Web, Flutter
